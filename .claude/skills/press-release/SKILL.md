# {브랜드명} 보도자료 초안 작성

{브랜드명} 마케팅팀 보도자료 패턴을 기반으로 초안을 작성합니다.

## Step 1: 유형 파악

`$ARGUMENTS`에서 보도자료 유형을 파악합니다. 명시되지 않으면 사용자에게 묻습니다.

| 유형 코드 | 설명 |
|-----------|------|
| `campaign` | 브랜드 광고 캠페인 오픈 |
| `promotion` | 프로모션 진행 |
| `product` | 신제품 출시 |
| `csr` | 사회공헌활동 |
| `award` | 디자인어워드 수상 |

## Step 2: 정보 수집

유형이 확인되면, 아래 필드를 채워달라고 요청합니다.
없는 항목은 생략해도 된다고 안내합니다.

### 브랜드 캠페인 오픈 (`campaign`)

```
캠페인명:
광고 모델: (없으면 생략)
캠페인 기간:
핵심 메시지/슬로건:
캠페인 내용: (영상, 채널 등)
주요 제품: (캠페인 연관 제품명/라인)
담당자 코멘트: (없으면 생략)
추가 정보: (없으면 생략)
```

### 프로모션 진행 (`promotion`)

```
프로모션명:
기간:
할인/혜택 내용:
대상 제품/라인:
참여 방법:
담당자 코멘트: (없으면 생략)
추가 정보: (없으면 생략)
```

### 신제품 출시 (`product`)

```
제품명:
제품 카테고리: (소파/침대/학생방 가구 등)
출시일:
핵심 특징/셀링포인트: (2~3가지)
가격대: (없으면 생략)
주요 타겟:
담당자 코멘트: (없으면 생략)
추가 정보: (없으면 생략)
```

### 사회공헌활동 (`csr`)

```
활동명:
일시/기간:
내용:
참여 대상/수혜자:
파트너 기관: (없으면 생략)
담당자 코멘트: (없으면 생략)
추가 정보: (없으면 생략)
```

### 디자인어워드 수상 (`award`)

```
어워드명:
수상 부문/등급:
수상 제품명:
수상 이유/심사평 요약: (없으면 생략)
어워드 권위/설명: (없으면 생략)
담당자 코멘트: (없으면 생략)
추가 정보: (없으면 생략)
```

## Step 3: 초안 작성

수집된 정보를 바탕으로 아래 구조에 맞게 보도자료 초안을 작성합니다.

### 공통 구조

```
[보도자료]

{슬로건 — {브랜드명} 브랜드 가치 한 줄 표현, 이탤릭체 느낌}

{메인 헤드라인 — 핵심 내용을 담은 한 문장, 제목 형식}

{서브 헤드라인 1 — 메인 헤드라인 보완, 유동적 1~3개}
{서브 헤드라인 2 — (있을 경우)}
{서브 헤드라인 3 — (있을 경우)}

{본문 단락들}
- 리드 단락: 육하원칙 기반, 핵심 정보 압축
- 상세 설명 단락: 캠페인/제품/활동 구체적 내용
- 브랜드/제품 소개 단락: {브랜드명} 브랜드 컨텍스트 연결
- 마무리 단락: 향후 계획 또는 기대 효과

{담당자 코멘트 — 있을 경우}
"코멘트 내용" 직책 이름

###

{사진자료}
- 사진 설명 (제공 자료 기준으로 작성)

{자료문의}
{브랜드명} 홍보팀 / 담당자 연락처
```

### 유형별 핵심 포인트

**브랜드 캠페인 오픈**
- 슬로건은 브랜드 철학과 캠페인 메시지 연결
- 모델이 있으면 헤드라인에 자연스럽게 포함
- 본문에서 캠페인 영상/콘텐츠 상세 설명 → 제품 연결 → 기대 효과 순서
- {브랜드명} 슬로건 "{브랜드 슬로건}" 컨텍스트 활용 가능

**프로모션 진행**
- 헤드라인에 혜택 규모 명시 (예: "최대 XX% 할인")
- 기간, 방법, 혜택을 서브 헤드라인으로 분산
- 본문에서 프로모션 상세 조건 명확히

**신제품 출시**
- 헤드라인에 제품명 + 핵심 차별점
- 서브 헤드라인으로 주요 기능/특징 강조
- 제품 스펙보다 라이프스타일 가치 중심 서술

**사회공헌활동**
- 따뜻한 톤, 구체적 수혜 내용 강조
- 기업 철학과 연결

**디자인어워드 수상**
- 어워드 권위 먼저 설명 후 수상 내용
- 수상 제품의 디자인 철학 연결

## Step 4: 초안 전달

초안 작성 후 아래 안내 문구를 함께 제공합니다:

```
📝 초안 완성!

수정이 필요한 부분이 있으면 알려주세요:
- 특정 단락 다시 쓰기
- 톤 조정 (더 공식적으로 / 더 부드럽게)
- 담당자 코멘트 추가/수정
- 헤드라인 대안 제시
```

## 작성 톤앤매너

- **브랜드**: {브랜드명}, 슬로건 "{브랜드 슬로건}"
- **톤**: 모던하고 세련된, 실용적이면서 감성적, 가족 중심 라이프스타일
- **문체**: 신문 보도자료 형식 (3인칭, 현재형 또는 완료형)
- **금지**: 과도한 수식어, 주관적 평가 표현 (예: "최고의", "압도적인")
- **권장**: 구체적 수치, 인용구, 브랜드 가치 연결
